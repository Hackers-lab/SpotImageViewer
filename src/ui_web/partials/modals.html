Excel Column Header Guide

File format & column arrangement specifications

When loading an Excel (.xlsx / .xls) or pasting tabular data into the Low Consumption Audit studio, arrange your columns in the following order:

Col Field Name Type Requirement
A (1) Consumer ID 9-digit number Mandatory
B (2) Meter Number Alphanumeric Optional
C (3) Billed Units Number / Float Optional (Default 0)
Example Excel Row:
Row 1: 502148901 | SP902144 | 18
Notes & Tips:
  • Header row (e.g. Consumer ID, Meter No, Billed Units) is automatically detected and skipped.
  • Any blank or invalid consumer rows are automatically ignored.
  • Your audit session is auto-saved as you verify each item.

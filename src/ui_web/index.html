Spot Image Viewer — User Guide & Help

v20.51 Studio Edition Documentation

1. Smart Universal Search

Enter a 9-digit Consumer ID, 10-digit Mobile number, alphanumeric Meter number, or consumer name into the top bar and press Enter.

Auto-detection instantly routes to the best index match without manual dropdown selection.

2. Spot Image Canvas

Pan images by dragging. Zoom smoothly with the mouse wheel or on-screen controls. Rotate 90° clockwise. Print or export single or bulk images instantly.

3. WBERC Bill Calculator

Calculate official Domestic, Commercial, Industrial, and Agricultural bills according to 2025-26 tariff schedules. Supports TOD peak/off-peak, 1-phase/3-phase meter rent, MVCA, and govt subsidies.

4. Section 126 & 135 Theft Assessment

Side-by-side Dual Ledger for Provisional vs Final assessments with automatic statutory relief check (flagged red if reduction exceeds the legal 25% ceiling).

5. RapidFuzz Batch Matching

Match external unmapped consumer lists against your local image database with configurable phonetic thresholds (default 85%) and top-N candidate ranking.

6. Global Settings & Folders

Attach network folders, trigger SQLite background re-indexing, update tariff rate slabs, import master consumer lists, and check for online software updates.

Excel Column Header Guide

File format & column arrangement specifications

When loading an Excel (.xlsx / .xls) or pasting tabular data into the Low Consumption Audit studio, arrange your columns in the following order:

Col Field Name Type Requirement
A (1) Consumer ID 9-digit number Mandatory
B (2) Meter Number Alphanumeric Optional
C (3) Billed Units Number / Float Optional (Default 0)
Example Excel Row:
Row 1: 502148901 | SP902144 | 18
Notes & Tips:
  • Header row (e.g. Consumer ID, Meter No, Billed Units) is automatically detected and skipped.
  • Any blank or invalid consumer rows are automatically ignored.
  • Your audit session is auto-saved as you verify each item.
